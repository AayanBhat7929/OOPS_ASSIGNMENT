# OOPS_ASSIGNMENT

Welcome to my **C++ Object-Oriented Programming (OOPS) Practical Assignments** repository!

This repository contains 10 C++ programming practicals completed as part of my B.Tech in Artificial Intelligence and Data Science.

The practicals cover fundamental to advanced programming concepts, including classes and objects, constructors, inheritance, polymorphism, templates, Standard Template Library (STL), exception handling, and file management.

The objective is to develop practical programming skills, understand object-oriented principles, and apply C++ concepts to real-world problem-solving scenarios.

---

## 🎯 Objectives

- Understand fundamental C++ programming concepts.
- Implement object-oriented programming principles.
- Develop programs using classes, objects, and constructors.
- Explore different types of inheritance and polymorphism.
- Understand memory management and resource handling.
- Implement generic programming using templates.
- Work with STL containers and algorithms.
- Handle runtime errors using exception handling.
- Perform file operations and CSV-based data management.
- Practise version control and maintain projects using GitHub.

# 🧪 Detailed Experiments

### Experiment 01 – C++ Fundamentals and GitHub Repository Setup

**Topics Covered:**

- Data Types
- Variables and Constants
- Operators
- Input and Output Operations
- Basic C++ Syntax
- GitHub Repository Management

**Description:**

Developed a C++ program demonstrating fundamental programming concepts such as data types, variable declarations, constants, operators, and input/output operations using `cin` and `cout`.

Also created a GitHub repository and practised maintaining source code using meaningful commit messages.

**Objective:** To understand the fundamentals of C++ programming and version control.

---

### Experiment 02 – Class Hierarchy and Access Specifiers

**Topics Covered:**

- Classes and Objects
- Encapsulation
- Public, Private and Protected Access Specifiers
- Member Functions
- Class Hierarchy

**Description:**

Designed and implemented a class hierarchy based on a real-world entity such as a Bank Account or Vehicle.

Demonstrated the use of access specifiers to control access to class data members and member functions.

**Objective:** To understand classes, objects, encapsulation, and access control in C++.

---

### Experiment 03 – Constructors and Rule of Five

**Topics Covered:**

- Default Constructor
- Parameterized Constructor
- Copy Constructor
- Move Constructor
- Destructor
- Rule of Five
- Dynamic Memory Management
- Valgrind

**Description:**

Implemented a C++ class demonstrating different constructor types, including default, parameterized, copy, and move constructors.

Applied the Rule of Five to manage dynamically allocated resources and explored memory leak detection using Valgrind.

**Objective:** To understand object initialization, resource management, and memory safety.

---

### Experiment 04 – Single and Multilevel Inheritance

**Topics Covered:**

- Inheritance
- Single Inheritance
- Multilevel Inheritance
- Base Classes
- Derived Classes
- Code Reusability

**Description:**

Implemented single and multilevel inheritance using a university management scenario.

The class hierarchy follows:

`Person → Student → GraduateStudent`

Demonstrated how derived classes inherit properties and functions from their respective base classes.

**Objective:** To understand inheritance and code reusability through hierarchical class structures.

---

### Experiment 05 – Runtime Polymorphism and Abstract Classes

**Topics Covered:**

- Runtime Polymorphism
- Virtual Functions
- Function Overriding
- Abstract Classes
- Pure Virtual Functions
- Dynamic Binding

**Description:**

Implemented runtime polymorphism using virtual functions and an abstract base class.

Created a Shape hierarchy consisting of Circle, Rectangle, and Triangle classes. Implemented an `area()` method to calculate the area of different shapes.

**Objective:** To understand runtime polymorphism, abstraction, and dynamic binding.

---

### Experiment 06 – Compile-Time Polymorphism

**Topics Covered:**

- Compile-Time Polymorphism
- Function Overloading
- Operator Overloading
- Matrix / Complex Number Operations

**Description:**

Developed a C++ program demonstrating compile-time polymorphism through function overloading and operator overloading.

Implemented overloaded operators for operations involving a Matrix or Complex Number class.

**Objective:** To understand how function and operator overloading enable different operations based on parameters and operands.

---

### Experiment 07 – Templates and Generic Programming

**Topics Covered:**

- Function Templates
- Class Templates
- Generic Programming
- Stack / Queue Implementation
- Multiple Data Types

**Description:**

Implemented a generic Stack or Queue class using C++ templates.

Tested the implementation using different data types:

- Integer (`int`)
- Floating Point (`float`)
- String (`std::string`)

**Objective:** To understand generic programming and develop reusable data structures.

### Experiment 08 – Standard Template Library (STL)

**Topics Covered:**

- Standard Template Library
- Vector
- Map
- Unordered Map
- Sorting Algorithms
- `sort()`
- `find_if()`
- `transform()`

**Description:**

Used STL containers and algorithms to process a student marks dataset.

Implemented vector, map, and unordered_map to store and organize student information. Applied STL algorithms for sorting, conditional searching, and data transformation.

**Objective:** To understand the practical application of STL containers and algorithms for efficient data processing.

---

### Experiment 09 – Exception Handling and Custom Exceptions

**Topics Covered:**

- Exception Handling
- try, catch and throw
- Custom Exception Classes
- Exception Hierarchy
- Runtime Error Management

**Description:**

Created a custom exception hierarchy and implemented a banking transaction scenario.

Used `try`, `catch`, and `throw` statements to identify and handle specific exceptions related to banking transactions.

**Objective:** To understand exception handling and improve program reliability through effective error management.

---

### Experiment 10 – File Handling and CSV Operations

**Topics Covered:**

- File Handling
- File Input and Output
- `ifstream`
- `ofstream`
- `fstream`
- CSV File Operations
- File Pointers
- `seekg()`, `seekp()`, `tellg()`, `tellp()`

**Description:**

Implemented a CSV file reader and writer using C++ file handling facilities.

Developed functionality to store and retrieve student records from files. Also explored file pointer operations to navigate through files and manage file positions.

**Objective:** To understand file handling, persistent data storage, CSV operations, and file pointer management.

## 💻 How to Run the Programs

**Prerequisites:**

- GCC/G++ compiler installed.
- Visual Studio Code or any compatible C++ IDE.
- Basic knowledge of C++.

**Step 1: Clone the Repository**

```bash
git clone https://github.com/AayanBhat7929/OOPS_ASSIGNMENT.git
```

**Step 2: Open the Repository**

```bash
cd OOPS_ASSIGNMENT
```

**Step 3: Compile a Program**

```bash
g++ Experiment-01.cpp -o output
```

**Step 4: Execute the Program**

For Windows:

```bash
.\output.exe
```

For Linux / macOS:

```bash
./output
```

Replace the filename with the program you want to execute.
